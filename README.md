# Sprint_7:  Автотесты для учебного сервиса API учебного сервиса Яндекс Самокат. Его документация: qa-scooter.praktikum-services.ru/docs/.

Тесты предназначены для проверки следующих сценариев:
1. Создание курьера
    Проверено:
        - курьера можно создать;
        - нельзя создать двух одинаковых курьеров;
        - чтобы создать курьера, нужно передать в ручку все обязательные поля;
        - запрос возвращает правильный код ответа;
        - успешный запрос возвращает {"ok":true};
        - если одного из полей нет, запрос возвращает ошибку;
        -если создать пользователя с логином, который уже есть, возвращается ошибка.
2. Логин курьера
    Проверено:
        - курьер может авторизоваться;
        - для авторизации нужно передать все обязательные поля;
        - система вернёт ошибку, если неправильно указать логин или пароль;
        - если какого-то поля нет, запрос возвращает ошибку;
        - если авторизоваться под несуществующим пользователем, запрос возвращает ошибку;
        - успешный запрос возвращает id.
3. Создание заказа
    Проверено, что, когда создаёшь заказ:
        - можно указать один из цветов — BLACK или GREY;
        - можно указать оба цвета;
        - можно совсем не указывать цвет;
        - тело ответа содержит track.
4. Список заказов
    Проверено, что в тело ответа возвращается список заказов.

Подготовлен Отчёт Allure.

При подготовке Автотеста был использован метод, который генерирует нового уникального пользователя, предоставленный для использования в проекте.
В результате запустов было выявлено 3 ошибки:
- при создании дубликата курьера ответ от сервера не корректен
- курьер успешно создается без firstName
- тест на авторизацию курьера без пароля упал из-за превышения времени ожидания ответа от сервера
